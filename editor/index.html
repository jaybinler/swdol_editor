        不同地图需要不同间隔时，请新增可见的地图变体。以下候选若切到其他模板，下一次间隔按实际模板计算。

        掉落道具（12 槽）

        输入物品编号与掉率；编号为 0 或 -1 表示空槽。修改后最多 8 个有效候选。掉率显示原生实际值。

        可释放技能（16 槽）

        0 或 -1 为空槽；保留重复槽位，不将重复次数直接解释为施放概率。

        此处编辑模板技能；原生 AI、自动脚本可能另行施放技能。施放概率和冷却控制尚未开放。
