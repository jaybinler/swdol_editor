# 轩辕剑网络版 · 道具工坊

Windows 本地内容编辑与查看工具，当前版本 **0.5.5**。

## 功能

- 按名称、编号和分类查看道具，展示原游戏图标及已确认属性。
- 预览原始三维资源与部分人物穿戴效果，支持旋转、缩放和线框。
- 人物穿戴的“自动匹配”根据道具要求的种族、性别及身体贴图兼容性选择基础人物；也可手动指定基础人物。
- 修改、复制道具，保存本地草稿并生成客户端／服务端配套离线补丁。
- 按出现地图查看 NPC 与怪物，统一预览模板基础外观。
- 地图索引合并存档关系与已解析的脚本生成关系；枯石等无直接存档的怪物也可按地图查找。关系保存在 v3 快照，离线查看无需原始脚本。
- 每种 NPC／怪物展示一份模板配置的物品清单，页面只显示“道具、掉率”，掉率为已计算的生成百分比。
- 集中配置游戏文件、NPC 快照与只读数据库连接，真实校验通过后才能保存；可用 Windows DPAPI 保护保存的数据库密码。

## 从源码运行

需要 Windows、Python 3.11 或更新版本，以及 Node.js／npm。

```powershell
git clone https://github.com/jaybinler/swdol_editor.git
cd swdol_editor/editor
npm ci
cd ..
.\启动道具编辑器.cmd
```

启动器会准备项目专用 Python 环境。打开本地页面右上角“设置”，选择匹配的客户端根目录、服务端 Object 文件及 NPC 数据来源，通过校验后保存。

本仓库只提供工具源码、测试和示例，不包含游戏客户端／服务端资源、数据库原始文件、NPC 快照、本机设置、密码、草稿、迁移包或内部研究记录。运行时需要自行准备游戏资源。

NPC 离线模式需要与服务端 Object 基线匹配的最小快照；数据库模式需要可读取 npcpool 与 npcpool_add_on 的连接、兼容 MySQL 客户端和区域目录。区域目录应包含地图配置、NewLocalServer.exe 与 ASM/TALK 编号脚本；只读校验后将解析关系写入快照。切换机器后重新定位路径、输入凭据并校验。数据库查询限于两张 NPC 表的白名单读取，页面使用本地快照。旧 v1／v2 快照仍可查看，但需更新 v3 才能补充脚本地图。

## 开发与测试

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests
```

多数集成测试依赖本地游戏资源及取证快照，纯源码检出不能直接复现完整测试结果。requirements-dev.txt 中的可选依赖用于复现静态分析。

## 目录

- editor：浏览器界面与 Three.js 预览。
- tools/xyj_content：文件解析、资源关联、草稿、快照与配置管理。
- tools/editor_server.py：仅监听本机回环地址的编辑器服务。
- tools/bootstrap.py：Windows 启动与专用环境准备。
- tests：解析、接口、状态隔离与安全边界测试。
- examples：道具修改示例。

部分工具用于历史本地取证或指定目标的部署验证，包含环境校验限制，不是通用部署入口。历史部署脚本要求通过 --share 显式指定 UNC 共享根目录，目标必须匹配本地静态快照证据及文件基线；不内置服务器地址。图形编辑器导出离线补丁；应用补丁前应自行完成基线核对和备份。

## 当前限制

模型以静态首帧预览为主，动画、染色、动态特效及部分装扮尚未完整还原。实例存档携带不等于运行中库存，模板生成判定不等于最终击杀掉率。完整游戏内验收仍需使用实际游戏环境进行。

脚本索引只沿已核验的指令边界、分支和入口建立可能生成关系，当前识别随机生成及指定坐标生成。遇到尚未解析的变长指令、对象／地图上下文切换会停止该路径，保留未覆盖统计；条件分支表示可能生成，不代表实时数量或刷新频率。脚本与游戏程序均只作静态读取，不会执行。
